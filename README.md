# Git-Github-Tutorial

This is a simple sample repository for learning Git and GitHub.
It is not a big project, but a beginner-friendly practice repo where I am learning how to create files, track changes, commit code, and push work to GitHub.

## What this repo contains
- A basic landing page built with HTML and CSS
- Simple files to practice Git commands
- A beginner-friendly example for learning version control

## How to open the page
Open the file named Index.html in your browser to view the landing page.

## Beginner Git commands
```bash
git init
git status
git add .
git commit -m "Your message"
git branch -M main
git remote add origin https://github.com/your-username/your-repo-name.git
git push -u origin main
```

## Beginner GitHub commands and steps
- Create a repository on GitHub
- Connect your local repo to GitHub
- Push your code using `git push`
- Create a pull request when you want to suggest changes

## Helpful Git commands
```bash
git clone <repo-link>
git pull
git log
git checkout -b new-branch
git merge branch-name
```

## Learning goal
The main goal of this repo is to practice Git and GitHub in a very simple way while building a small web page.

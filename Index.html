Git & GitHub Tutorial

Learning Git and GitHub feels easier when you practice step by step. This page is a simple guide for beginners who want to understand the basics without getting lost.

Use the Git & GitHub cheat sheet to get all the commands you need — by Code With Harry.

Why Git matters

Git helps you save your work safely, track changes, and work with others without losing progress.

Useful commands

  • git init — start a new repository.
  • git clone — copy a project from GitHub.
  • git status — check your current changes.
  • git add . — stage everything ready to commit.
  • git commit -m — save your changes with a message.
  • git push — send your work to GitHub.
